# peak-flex
A flexible Nextflow pipeline for the read combination, trimming, mapping, deduplication, peak calling and bigwig creation using a the DiffBind background windowed approach of inter-sample normalization. 

## Docker
All software used in this pipeline is available via Docker. Feel free to use Docker or convert to a Singularity container when running the pipeline.

https://hub.docker.com/r/nolandocker/peak-flex
